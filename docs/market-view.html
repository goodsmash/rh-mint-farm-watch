ℹ️ About This Tool

This is a read-only on-chain market analytics dashboard for OpenSea Seaport NFT sales. Every sale is recorded as an OrderFulfilled log in the Seaport contract on each chain. This page replays those logs directly from the chain — no API key, no upload, read-only.

Supported chains:
• Base (8453) · • Ink (11111, ERC-1155 + ERC-721)
• Ethereum (1) · • ApeChain (33139) · • Robinhood (4663)

OpenSea link format: https://opensea.io/assets/{chain-slug}/{contractAddress}
Master tools:
📊 Volume breakdown (1-7 day) · 🏆 Top collections · 🔍 Wallet audit · 🫧 Connected projects · 👥 Holders · 🚩 Flags
Data source: each chain's Seaport contract (OrderFulfilled topic 0x9d9af8e38d66c62e2c12f0225249fd9d721c54b83f48d9352c97c6cacdcb6f31). Block explorers: Blockscout for all chains.

Flags = structural on-chain evidence (paid-for-mints, sweep, automated mints, machine timing) from the 24h scan. Read-only — no wallet connect, no signing, nothing confidential.
