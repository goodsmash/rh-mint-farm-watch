ℹ️ About

OpenSea Seaport is the on-chain marketplace for NFT sales. Every sale is recorded as an OrderFulfilled log in the Seaport contract on each chain. This page replays those logs directly from the chain — no API key, no upload, read-only.

Supported chains: Base (8453), Ink (11111, ERC-1155 + ERC-721), Ethereum (1), ApeChain (33139), Robinhood (4663). OpenSea link format: https://opensea.io/assets/{chain-slug}/{contractAddress}
Master tool list: Volumes (1-7 day), Top collections (ranked by volume), Wallet audit (fungible wallets for buys/sells), Connected-project graph (bubble graph, shared wallets → proximity), Holders (per collection).
Data source: each chain's Seaport contract (OrderFulfilled topic 0x9d9af8e38d66c62e2c12f0225249fd9d721c54b83f48d9352c97c6cacdcb6f31). Block explorers: Blockscout for all chains. Web: opensea.io.

Flags = structural on-chain evidence (paid-for-mints, sweep, automated mints, machine timing) from the 24h scan. Read-only — no wallet connect, no signing, nothing of ours is confidential.
